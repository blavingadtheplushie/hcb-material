# HCB (unofficial Material You client)

An unofficial, native Android client for [HCB](https://hcb.hackclub.com) (Hack Club's fiscal sponsorship bank),
written in Kotlin + Jetpack Compose with **Material 3 Expressive** and your phone's **dynamic (Material You) colours**.

- Sign in with HCB (OAuth2 + PKCE, Auth Tab), same flow as the official app
- Organizations with balances, day-grouped transactions with search and filters, infinite scroll
- Transaction details, receipts (camera or file), "no receipt", comments, renaming
- Cards (freeze / defrost), receipt bin and missing receipts, invitations
- Light / dark / system theme, hide balances

Download the latest APK from [Releases](../../releases) (`universal` works everywhere, `arm64-v8a` for most phones).

Design inspired by [BetterAttend](https://github.com/ingoau/better-attend). Not affiliated with Hack Club.
